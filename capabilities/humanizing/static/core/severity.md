# Severity

| 级别 | 含义 | 默认动作 |
|---|---|---|
| `low` | 弱候选：单个高频词、三项并列、段末短句 | 结合上下文决定；可保留 |
| `medium` | 较明显的模板化：套话收尾、词群密集、限定词堆叠 | 通常改写；保留真实限定 |
| `high` | 高置信模板：模糊归因、意义拔高、宣传语、假权威 | 必须处理或说明保留理由 |
| `error` | 与数字/引用/情态/归因重叠，或可能改变事实 | 停止自动改写；人工复核 |

## 使用原则

- 不按数量机械改；同一段多个 `low` 可以合并判断。
- 不把 `high` 当成“必须删除”；有真实信息时保留核心，只删空泛外壳。
- `error` 不允许通过 `auto_fixable` 自动处理；扫描器始终 `auto_fixable: false`。
