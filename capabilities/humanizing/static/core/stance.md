# Humanizing Stance

## 核心原则

1. **扫描器只报候选**：命中不是判决，单个词、标点、三项列表都不是修改理由。
2. **保留事实与确定程度**：数字、引用、否定、情态、范围、时间、归因、作者立场不得改变。
3. **不新增内容**：不补案例、数据、文献、页码、机构名、实现细节或性能结论。
4. **最小改动**：只改确实空泛、重复、模板化的句子；没问题的段落原样保留。
5. **不自动改写**：扫描器不生成替换文本；Agent 改写后必须走 edits.json 和人工验收。

## 不做什么

- 不把学术正式表达强行口语化。
- 不把被动、四字格、名词化、必要的过渡词当 AI 痕迹。
- 不把“可能/相关/未发现”改成“确定/导致/证明”。
- 不替作者补造来源或把无来源权威改成自己的事实断言。
