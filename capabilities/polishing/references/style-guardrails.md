# Style Guardrails — 风格质量检查

## 通用质量检查

### 清晰度
- [ ] 每句的核心意思能否在5秒内被理解？
- [ ] 是否有可以删掉而不影响意思的词？
- [ ] 代词（这/其/该）的指代是否明确？

### 简洁度
- [ ] 是否有冗余修饰语（"非常重要""极其显著"）？
- [ ] 是否有可以用一个词代替的短语？
- [ ] 是否有重复表述（同一观点用不同说法说了两次）？

### 一致性
- [ ] 术语是否全篇统一？
- [ ] 时态是否一致？
- [ ] 格式（编号/缩进/字体）是否统一？

## 中文学术写作特有检查

### 标点
- [ ] 中文标点使用全角（，。；：、！？）
- [ ] 英文标点使用半角（,.;:!?）
- [ ] 引号统一使用全角（""）
- [ ] 括号内的中文文献注释使用全角标点

### 数字
- [ ] 中文正文中的数字何时用汉字、何时用阿拉伯数字一致
- [ ] 一般规则：计数/统计值用阿拉伯数字，成语/固定搭配用汉字

### 参考文献
- [ ] 正文引用标记与参考文献列表一一对应
- [ ] 编号连续，按首次出现顺序排列
- [ ] 文献格式与目标期刊/学校要求一致
