# Chinese Academic Polishing — 中文学术语体润色

## 语言诊断清单

### 口语化检测
将以下口语表达替换为书面表达：
- "做了" → "进行了/实施了"
- "很多" → "大量/诸多"
- "总的来说" → "总体而言/综上所述"
- "这样的话" → "据此/由此"
- "因为...所以" → "由于...因此"

### AI痕迹检测
扫描并删除以下模式：
- "在当今时代/社会背景下"
- "众所周知/毋庸置疑"
- "具有重要意义/深远影响"
- "提供了宝贵的参考/借鉴"
- "值得注意的是/值得强调的是"
- "不仅...而且..."（过度使用）
- "综上所述/总而言之"（段落中间使用）

### 动词精确化
- "研究" → 具体化为 探讨/考察/验证/分析/评估
- "做" → 具体化为 进行/实施/开展/执行
- "说明" → 具体化为 表明/指出/揭示/证实

### 句子长度
- 超过50字的句子 → 拆分为2句
- 连续短句（<10字） → 合并为复合句
