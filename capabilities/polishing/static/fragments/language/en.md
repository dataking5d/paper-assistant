# English Academic Polishing

## Language diagnostics

### Weak verbs → strong verbs
- "is about" → "examines / investigates / explores"
- "talks about" → "discusses / addresses"
- "looks at" → "analyzes / evaluates / assesses"
- "shows" → "demonstrates / reveals / indicates"

### Filler phrases to remove
- "It is worth noting that..." → Delete, just state the point
- "It should be noted that..." → Delete
- "It is important to mention..." → Delete
- "In other words,..." → Rephrase the previous sentence instead

### Sentence rhythm
- Vary sentence openers (don't start every sentence with "We...")
- Mix short punchy sentences (8-12 words) with longer analytical ones (20-25 words)
- Use semicolons and em-dashes sparingly in formal academic prose

### Hedging calibration
- Claim → evidence → hedge match
- Strong evidence: "demonstrates / establishes"
- Moderate evidence: "suggests / indicates"
- Weak evidence: "may / might / could"
