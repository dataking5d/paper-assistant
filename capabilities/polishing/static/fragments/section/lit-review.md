# Literature Review Polishing — 文献综述润色

## 检查重点
1. 文献是否按主题组织（而非按时间堆砌）？
2. 每篇文献是否有评价（而不只是描述）？
3. 段落之间是否有逻辑过渡？
4. 是否以研究缺口作为结尾？

## 常见问题及修复
- 文献堆砌："A研究了X。B研究了Y。C研究了Z。" → 主题整合
- 缺少评价："A提出了X理论" → "A提出了X理论，其核心贡献在于...，但其局限是..."
- 过渡缺失：在主题变化处添加过渡句

## 引用密度检查
- 每个主要主张至少有一篇文献支撑
- 同一主张不需要堆砌3篇以上的文献
- 弱主张（常识性内容）不需要引用
