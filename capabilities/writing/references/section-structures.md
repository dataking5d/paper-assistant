# Section Structure Examples

## Introduction — 漏斗型结构
```
[第1段] 研究领域的重要性 (Why this field matters)
[第2段] 已有研究做了什么 (What we know)
[第3段] 已有研究没做什么 (What we don't know → Gap)
[第4段] 本文要做什么 (What this paper does → Research question)
[第5段] 本文的贡献 (Contributions)
[第6段] 本文结构 (Paper structure)
```

## Literature Review — 主题型结构
```
[小节1] 主题A的研究进展
  - 贡献1: ...
  - 贡献2: ...
  - 局限: ...
[小节2] 主题B的研究进展
  - ...
[小节3] 研究述评
  - 共识: ...
  - 争议: ...
  - 缺口: ... → 本文要解决的问题
```

## Method — 过程型结构
```
[小节1] 研究设计概述 (Research design overview)
[小节2] 数据来源 (Data sources)
[小节3] 分析方法 (Analytical methods)
[小节4] 有效性/可靠性保障 (Validity/reliability measures)
```

## Results — 逻辑型结构
```
[小节1] 描述性统计 (Descriptive statistics)
[小节2] 主要分析 (Main analysis — 回答核心研究问题)
[小节3] 补充/稳健性分析 (Supplementary analyses)
```

## Discussion — 对话型结构
```
[小节1] 主要发现回顾 (Recap of key findings)
[小节2] 与已有研究的对话 (Dialogue with literature)
[小节3] 理论贡献和实践含义 (Theoretical & practical implications)
[小节4] 局限性 (Limitations)
[小节5] 未来方向 (Future directions)
```
