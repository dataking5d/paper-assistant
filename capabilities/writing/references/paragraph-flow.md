# Paragraph Flow Check — 段落流畅性检查

## 检查清单

对每个段落运行以下检查：

### 单一任务检查
- [ ] 这个段落是否只做一件事？（背景/缺口/方法/结果/比较/机制/含义/局限）
- [ ] 是否有"任务泄漏"——在方法段落里讨论结果，在结果段落里讨论方法？

### 主题句检查
- [ ] 第一句是否明确了段落的主题？
- [ ] 读者只读第一句能否知道这段要讲什么？

### 句间关系检查
对段落中相邻的每两句，问：第二句与第一句的关系是什么？
- 因果: A → B
- 递进: A → 更进一步
- 转折: A → 但是...
- 例证: A → 例如...
- 解释: A → 这意味着...
- 限制: A → 然而这个结论受限于...

如果两句之间没有明确的逻辑关系，重写其中一句或添加连接词。

### 反向大纲检查
1. 提取每个段落的主题句
2. 只读这些主题句
3. 它们是否构成了一个连贯的论证链？
4. 如果只读主题句就能理解章节的论证，段落结构是正确的
