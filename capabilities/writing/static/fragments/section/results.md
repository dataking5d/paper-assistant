# Results Writing — 结果写作

## 结构原则
按研究问题的逻辑顺序呈现结果，不是按你做实验的时间顺序。

### 呈现顺序
1. 描述性统计 → 整体数据特征
2. 主要分析结果 → 回答核心研究问题
3. 补充/稳健性分析 → 支持主要发现的额外证据

## 写作规则
- **事实与解读分离**: 结果章节只呈现事实（是什么），讨论章节才解读（为什么/意味着什么）
- **数据驱动叙述**: 让数据讲故事的顺序是：期待什么 → 做了什么 → 发现了什么 → 这意味着什么（初步）
- **每个图表都需要文字说明**: 引导读者关注关键发现
- **使用一致的格式**: 所有统计值使用相同的小数位、计量单位

## 常见问题
- 避免：在结果章节深度解读（留到讨论）
- 避免：选择性报告（只报告显著结果）
- 避免：用文字重复图表中的所有数据（只指出关键发现）
- 避免："我们发现..."; "有趣的是..." → 删除主观评价
