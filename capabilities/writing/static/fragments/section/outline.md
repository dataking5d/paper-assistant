# Outline Generation — 大纲生成

## 大纲结构
为一个完整的论文章节生成大纲，包含：
1. 章节标题
2. 小节标题
3. 每个小节的段落规划（每段一个任务）
4. 每段的关键要点

## 大纲格式
```
## [章节名称]

### [小节1名称]
- 段落1 (任务: context/gap/approach/result/comparison/implication)
  - 要点: ...
  - 需引用的文献: [具体概念或作者]

### [小节2名称]
- 段落1 (任务: ...)
  - 要点: ...
```

## 生成原则
- 每个小节约3-5个段落
- 每个段落标注单一任务类型
- 标注需要引用文献支持的位置（[需要引用: 概念]）
- 考虑章节在论文整体中的位置和功能
