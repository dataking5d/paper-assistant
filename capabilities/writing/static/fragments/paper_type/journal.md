# Journal Article Writing — 期刊论文写作

## 整体结构
IMRaD 结构（大多数实证期刊）：
1. Introduction — 背景 → 缺口 → 问题 → 方法概述 → 贡献
2. Methods — 可复现的详细描述
3. Results — 事实呈现
4. Discussion — 解读 + 与已有研究对话 + 含义 + 局限

## 期刊论文 vs 学位论文
- 期刊论文需要更精炼：每个词都要有价值
- 引言要快速建立研究问题：不需要长篇幅的背景铺垫
- 文献综述要聚焦：只引用与本文直接相关的研究
- 方法要有选择性：详细但不过于琐碎
- 讨论要有对话感：与具体研究对话，不是泛泛的文献综述

## 常见期刊长度限制
- Nature/Science: 2000-3000字正文
- Nature Communications: 5000-8000字
- 领域顶刊: 6000-10000字
- 中文核心期刊: 8000-15000字

## 投稿前自查
- [ ] 摘要是否自包含（不依赖正文即可理解）
- [ ] 引言是否在3段内建立了研究问题
- [ ] 每张图表是否在正文中被引用
- [ ] 参考文献格式是否与目标期刊一致
- [ ] 是否存在夸大或绝对化的声明
