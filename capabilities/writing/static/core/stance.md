# Writing Stance — 写作立场

## 核心原则

1. **从证据向外写** — 每个观点都必须有数据或文献支撑，观点紧贴证据，不要堆砌空泛声明在段落开头
2. **一段落一任务** — 每个段落只做一件事：背景/缺口/方法/结果/比较/机制/含义/局限
3. **动词对齐证据强度** — "证明/揭示"需要强证据；"表明/暗示"用于趋势级证据；"可能/也许"用于未经验证的机制
4. **删除无依据的声明** — 扫除"首创""独一无二""全面""完整的""总是""绝不"等绝对化表达

## 不可接受的AI写作痕迹

禁止使用的表达：
- "在当今时代/社会" — 模糊时间锚定
- "众所周知/毋庸置疑/不言而喻" — 冗余强调
- "具有重要意义/深远影响" — 空洞价值判断
- "提供了宝贵的参考/借鉴/启示" — 泛泛赞誉
- "值得注意的是/值得强调的是" — 过度过渡
- "不仅...而且..." — 过度并列

## 中文学术写作特殊要求

- 使用正式书面语，不用口语表达
- 避免第一人称（我/我们），除非论文本身使用
- 不用反问句、不用感叹号
- 优先使用精确动词：指出/论证/揭示/验证 > 研究/探讨/分析
- 术语一致性优先于词汇多样性
